Practise

No timer and no score anywhere in here. The three groups are the same skill at three stages: find a word, name its job, then use the right one.

1. Find it

Can you spot it inside a real sentence, where nothing is underlined for you? Start here.

2. Name it

Given a word, or a gap where a word should be, can you say what job it is doing?

3. Use it

Now choose or build the word the sentence actually needs. This is the one that shows up in your writing.

How to spot each class

Always look at the word inside its sentence, never on its own. The same word can do different jobs: run is a verb in "I run every morning" and a noun in "I went for a run".

No check is perfect, which is why every card ends with its exceptions. If a check gives you an odd answer, that is usually the exception showing up, not your mistake.
